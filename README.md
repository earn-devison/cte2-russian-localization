# CTE2 Russian Localization

Русская локализация для **Craft to Exile 2 — 2.0 Atlas Update** (Minecraft 1.20.1, Forge).
Классы, заклинания, квесты и награды уже переведены на стороне сервера.

## Файлы релиза

Скачать: [Releases](../../releases/latest)

| Файл | Что это | Как ставится |
|---|---|---|
| `CTE2-RU-Pack.zip` | Ресурспак: предметы, классы, таланты, статы, книги, меню | **Автоматически** — сервер отдаёт пак при входе |
| `CTE2-RU-FancyMenu.zip` | Перевод экранов FancyMenu: выбор класса, таланты, умения, самоцветы | **Вручную** (инструкция ниже) |

## Установка

### 1. Ресурспак — делать ничего не нужно

При входе на сервер прими загрузку ресурспака. Сервер настроен на обязательный пак.

Обязательно: **Настройки → Язык → Русский**. Без русского языка в настройках перевод не применяется.

### 2. FancyMenu (выбор класса и др.) — вручную один раз

1. Скачай `CTE2-RU-FancyMenu.zip` со страницы [Releases](../../releases/latest).
2. Распакуй **содержимое** архива в папку `minecraft/config/fancymenu/customization/` своего инстанса, с заменой файлов:
   - **PrismLauncher:** ПКМ по инстансу → папка инстанса → `minecraft/config/fancymenu/customization/`
   - **CurseForge App:** настройки профиля → Open Folder → `config/fancymenu/customization/`
3. Полностью перезапусти игру.

## Проверка

Зайди на сервер: экран выбора класса и меню талантов — на русском.

## Если что-то не так

- **Классы/меню английские** — не распакован FancyMenu-архив, распакован не в ту папку или игра не перезапущена после копирования.
- **Вообще всё английское** — в настройках игры стоит не русский язык.
- **Сервер не пускает без ресурспака** — прими загрузку пака при входе, без него играть нельзя.
