# CTE2 Russian Localization

Русская локализация для **Craft to Exile 2 — 2.0 Atlas Update** (Minecraft 1.20.1, Forge).
Классы, заклинания, квесты и награды уже переведены на стороне сервера.

## Файлы релиза

Скачать: [Releases](../../releases/latest)

| Файл | Что это | Как ставится |
|---|---|---|
| `CTE2-RU-Pack.zip` | Ресурспак: предметы, классы, таланты, статы, книги, меню | **Автоматически** — сервер отдаёт пак при входе |
| `CTE2-RU-FancyMenu.zip` | Перевод экранов FancyMenu: выбор класса, таланты, умения, самоцветы | **Вручную** (инструкция ниже) |
| `Install-CTE2-RU.bat` | Установщик для друзей | Запуск двойным щелчком |

## Установка

### Ресурспак

При входе на сервер прими загрузку ресурспака. Сервер настроен на обязательный пак.
Обязательно: **Настройки → Язык → Русский**.

### FancyMenu вручную

Скачай `CTE2-RU-FancyMenu.zip` и распакуй **содержимое** в `minecraft/config/fancymenu/customization/` с заменой файлов. Полностью перезапусти игру.

### Быстрый установщик

1. Скачай `Install-CTE2-RU.bat` со страницы [Releases](../../releases/latest).
2. Запусти двойным щелчком. Он найдёт PrismLauncher/CurseForge, скачает свежие файлы, проверит SHA256 и установит перевод.
3. Если найдено несколько инстансов, выбери нужный номер.
4. Перезапусти Minecraft.

Установщик не требует прав администратора и не трогает моды. Для нескольких инстансов запусти `Install-CTE2-RU.ps1 -AllMatching`.

## Если что-то не так

- Английский остался в классах или меню: проверь папку `config/fancymenu/customization/`, замени файлы и перезапусти игру.
- Вообще всё английское: выбери язык «Русский».
- Сервер не пускает: прими загрузку обязательного ресурспака.
